# 探索台灣 TaiwanExplorer

使用 Angular 與 Leaflet 建立的台灣景點地圖，提供搜尋、多選篩選、定位，以及儲存在私人 Google Drive 的個人地點紀錄。

[開啟網站](https://melodypan.github.io/TaiwanExplorer/) · [文件總覽](docs/README.md)

完整文件集中在 docs，請依需要閱讀：

- [使用指南](docs/使用指南.md)
- [開發維護說明](docs/開發維護說明.md)
- [Google Drive 設定](docs/GoogleDrive設定.md)
- [測試與發布](docs/測試與發布.md)

本專案採瀏覽器端渲染（CSR），未使用 SSR。日常操作及個人紀錄設定見文件，開發、測試與發布指令見「測試與發布」。
