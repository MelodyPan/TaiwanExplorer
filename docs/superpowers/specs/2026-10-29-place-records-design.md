# 個人地點紀錄（使用者已確認）
沿用 Home bookmarks：Google OAuth drive.file，私人 Drive，每台裝置登入同一帳號存取同一資料集。公開地點資料照常免登入瀏覽。
每個地點使用既有穩定 id 保存 1–5 星或未評分、去過/沒去過/未設定、好停車/不好停車/未設定、季節限定/非限定/未設定與限定說明。
地圖彈窗與清單皆可開啟 Angular 編輯視窗。獨立 purpose、資料夾與每日檔案，不修改書籤。沿用每日條件寫入、帳號驗證、失敗重試與明確選擇衝突版本；草稿僅記憶體，提供下載備份。
方案：本機儲存不符跨裝置需求；新伺服器增加維護；使用者已選擇現有 Drive 流程。
保留篩選預設隱藏、定位說明在地圖下方及既有未提交依賴變更。
