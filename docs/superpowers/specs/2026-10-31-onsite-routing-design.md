# 站內免費路線規劃設計

使用者確認希望直接在本站操作，支援開車、騎機車及步行，且不需要付費。

## 方案
- 開啟 Google Maps：不需金鑰，但會離開本站；使用者已改選站內操作。
- 商用 API：需要帳號、金鑰及費用管理，不符合免費要求。
- 採用 Valhalla 公共服務：不需金鑰，保留 Leaflet，使用 auto、motor_scooter、pedestrian 三種獨立計算模式。公共服務無可用性保證，僅適合少量互動查詢。

## 操作
點推薦地點後捲回地圖，置中並打開該地點資訊。資訊內的「規劃路線」在本站計算並畫線；地圖下方顯示目的地、三種交通方式、預估時間與距離、重試與清除。
一般機車採 motor_scooter，不以汽車路線或單車路線代替，不支援重機特別規則。時間不含即時路況。
只有使用者要求規劃或切換已規劃的模式才傳送目前位置與目的地座標。IP 起點標示推估；無有效定位提示重新定位，不以預設車站冒充。
切換目的地、模式、清除或離頁時取消舊請求，舊結果不可覆蓋新選擇。保留原有左滑編輯與無障礙入口。

## 公共服務
端點 https://valhalla1.openstreetmap.de/route；提供 X-Client-Id 識別、至少 1.1 秒請求間距與短期記憶體快取，無背景批次規劃。
頁面提供 Valhalla / FOSSGIS / OpenStreetMap 出處與修改地圖連結。維運方請公開應用向其 GitHub Discussions 告知用途；此為公開用途通知，不是付費或金鑰申請。對外發文另取得使用者授權，不自動代發。
