# 使用指南

[返回文件總覽](README.md)

## 搜尋與篩選

在搜尋列輸入景點名稱、縣市、地區或說明中的文字。點「篩選」才會展開整個篩選區，預設為隱藏。

類別與縣市都可複選，各自可展開、收合與清除。同一組的多個選項表示任一符合；類別、縣市與搜尋文字之間則必須同時符合。例如同時選臺中市、臺南市，以及美食、咖啡，會顯示這兩個縣市中的美食或咖啡地點。

收起篩選區不會清空勾選。清單與地圖使用同一組條件；地圖只繪出目前範圍中的地點。

取得有效裝置定位或 IP 推估位置後，地點清單會依與目前位置的距離由近到遠排列；位置更新及篩選改變時也會重新排序。距離採球面直線距離，不是開車或步行路程；IP 排序受定位誤差影響。尚未定位或定位失敗時維持原順序，台中火車站的預設中心不會用來排序。

## 地圖與定位

點地圖上的地點圖示可查看名稱、地址、說明與外部地圖連結，也能開啟「我的地點紀錄／編輯」。

手機優先使用瀏覽器的裝置定位；電腦使用 IP 推估。手機未允許或無法取得裝置定位時，也會嘗試 IP 推估。藍點表示取得的定位，周圍圓圈表示誤差範圍；IP 位置不是精確 GPS。

定位說明放在地圖下方。拖動地圖後，點「回到目前位置」會把最新位置放回中央，保留目前縮放倍率。後續定位更新會移動藍點，不會持續把使用者拖開的地圖拉回。

若無有效定位，預設中心為台中火車站；這只是地圖中心，不會冒充使用者位置。可再次點定位按鈕重試。

## 個人地點紀錄

1. 點「連接 Google Drive」，完成 Google 帳號授權。
2. 第一次使用時，點「建立我的地點紀錄」。
3. 登入後，在清單的某一筆資料往左滑，才會出現該筆「編輯」按鈕。
4. 點「編輯」開啟視窗，填寫後按「儲存到 Google Drive」。

清單預設不顯示編輯按鈕；右滑可收起，一次只會展開一筆。上下捲動不會當成左滑。電腦可用 Tab 選取資料列，按左方向鍵顯示編輯，再用 Tab 移到按鈕；右方向鍵或 Escape 可收起。螢幕閱讀器另有「顯示某地點的編輯按鈕」入口，平常視覺畫面不會顯示。

| 欄位 | 可維護內容 |
| --- | --- |
| 類別 | 景點、美食、咖啡、住宿、文化、自然；或沿用網站原始類別 |
| 個人評價 | 1～5 顆星，也可清除為未評分 |
| 是否去過 | 去過、沒去過、未設定 |
| 是否好停車 | 好停車、不好停車、未設定 |
| 季節限定 | 是、否、未設定；選「是」時可輸入最多 1,000 字的說明 |

類別修改是私人紀錄，不會改動公開景點資料；清單、地圖圖示與類別篩選都會使用登入帳號設定的分類。選「沿用網站原始類別」可恢復；登出後也會使用公開分類。目前提供改選既有六種類別，沒有新增或刪除類別的管理畫面。

清單只顯示已填寫的星等與是否去過；未評分、未設定不顯示，兩項都未填時不保留摘要行。編輯視窗仍提供未設定與清除評分選項。

未設定與「否」不同，不會把尚未填寫的資料當成沒去過或不好停車。季節限定改為「否」或未設定後再存檔，會清除季節說明。

## 同步、草稿與備份

手機與電腦登入同一個 Google 帳號，會讀取同一份私人 Drive 資料。畫面顯示「已儲存到 Google Drive」才表示完成；只在表單輸入文字不等於已存檔。

關閉視窗再開啟，未提交的表單會保留在同一分頁的記憶體。重新整理或關閉分頁會失去這些表單；離開前如有未存內容會提醒。可使用「下載備份」或「下載草稿備份」保留 JSON。

若有版本衝突，先下載備份，再明確選擇目前草稿或雲端版本；系統不會悄悄合併或覆蓋另一台裝置。若開啟的表單已落後於背景同步結果，儲存會被阻擋，可先備份再按「重新載入此地點」。

Google 授權到期後需要重新連接原帳號。若有原帳號草稿，不能換成另一個帳號繼續寫入。若重新授權失敗導致雲端文件暫時清空，請先連回原帳號，才能下載尚未提交的表單備份；記憶體中的草稿仍保留。

## 回到頁首

整個頁面往下捲動超過約 300 像素後，右下角會顯示「上」按鈕。點擊可回到頁首，回到上方後按鈕會隱藏。若系統設定減少動態效果，會直接返回，不播放平滑捲動。

## 站內免費路線規劃

點推薦地點清單中的地點，會捲回地圖、定位到該景點並打開詳細資訊。左右滑仍用於顯示或收起編輯，不會啟動地圖跳轉。

點「規劃路線」後留在本站，地圖會畫出路線；下方可切換開車、機車、步行，並顯示預估時間與距離。機車是一般機車模式，非重機專用。路線以地圖資料的通行限制計算，實際仍依現場標誌通行。

使用免費 Valhalla / FOSSGIS 公共服務，不需要 API 金鑰；服務暫時無法使用時可稍後重試。時間不含即時路況。這是路線規劃，沒有語音導航。

只在按下規劃或切換已規劃的交通方式時，將當時的起點與目的地座標傳給路線服務。後續 GPS 更新不會自動重新計算；可按「依目前位置重新規劃」。起點若是 IP 推估，畫面會明確提醒誤差。沒有有效定位時，先按定位按鈕重試；不會把台中火車站當成你的出發點。

「清除路線」保留目的地；「關閉」會收起面板。切換目的地會取消上一筆路線。點地圖圖示也能從資訊窗啟動規劃。
