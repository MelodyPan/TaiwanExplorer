## 本機開發

在專案根目錄執行：

```powershell
npm ci
npm start
```

目前專案的 start 指令為 ng serve，預設網址通常是 http://localhost:4200/；以終端顯示為準。使用 Google 登入前，先將實際本機來源加入 OAuth 設定。

現有回歸測試使用 Node.js 22 的測試執行器、fetch 與 Response。Angular 14 是既有舊版工具鏈，若更換 Node 或升級套件，應獨立評估相容性；不要為了文件整理順便更新依賴。

## 回歸測試

```powershell
node --test tests/*.test.cjs
```

主要覆蓋篩選交集、地圖彈窗、裝置與 IP 定位、距離排序、回到位置、左滑編輯、回到頁首、個人類別、舊檔相容、每日存檔、ETag 衝突、上傳回應遺失、授權到期、帳號切換及表單草稿。

目前 npm test -- --watch=false 的 Angular 測試設定存在既有問題：tsconfig.spec.json 繼承排除所有 spec 的設定，會遇到 TS18003。它不等於業務測試失敗；目前使用上述 Node 回歸測試與實際建置驗證。尚未將這個舊測試設定修復，不能宣稱 npm test 已通過。

## 建置與本機預覽

GitHub 專案網站路徑需要指定 base href：

```powershell
npm run build -- --base-href /TaiwanExplorer/
node tests/preview-server.cjs
```

產物位於 dist/TaiwanExplorer，預覽網址為 http://127.0.0.1:4173/TaiwanExplorer/。

附加 ?mock=1 可開啟明確標示的模擬 Google Drive 測試頁。它替換登入與 Drive 請求，以記憶體模擬資料，不會存入真實帳號；重載後模擬資料也會重設。模擬程式只在本機測試伺服器注入，不能加入正式建置腳本或把測試頁當成雲端驗收。

建置可能顯示 Leaflet 的 CommonJS 最佳化警告；目前屬既有警告。仍應確認命令退出碼為 0，而非只看到部分建置訊息。

## GitHub Pages 發布

原始碼分支為 main，部署分支為 gh-pages，公開網址為 https://melodypan.github.io/TaiwanExplorer/。先確認提交範圍，避免混入未授權的依賴或私人資料，再推送原始碼。

使用已安裝的發布工具，不需臨時下載：

```powershell
node node_modules/angular-cli-ghpages/angular-cli-ghpages --dir dist/TaiwanExplorer --branch gh-pages --message "更新網站"
```

此命令會把建置產物推送至遠端，應在要發布且 GitHub 已授權時執行。若電腦有多個 GitHub 帳號，應明確使用擁有該儲存庫寫入權限的帳號；不要把帳號選擇或 Credential Manager 等待誤認為已成功。

發布工具回報成功後，Pages 仍可能需要一段時間才提供新版。請確認線上 index.html、main.js、scripts.js 的內容或雜湊與本次建置一致，再宣布已上線；只看到舊網站正常開啟不代表部署完成。

## 驗收重點

- 手機預設不顯示篩選區及資料列編輯按鈕；左滑只展開一筆，點編輯才開視窗。
- 取得定位後，清單由近到遠；位置更新與篩選後維持正確順序，無定位不以預設中心排序。
- 分類改動後，清單、圖示、彈窗與篩選同步；清除覆寫或登出恢復公開類別。
- 往下捲整頁後右下角出現「上」，點擊回到頁首並隱藏。
- Google 真實帳號可在手機、電腦讀寫同一份資料，另一個帳號不能接手未存草稿。
- 定位失敗顯示台中火車站中心，不把它標成目前位置；定位說明在地圖下方。
