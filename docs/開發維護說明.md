## 實際技術與入口

依目前套件設定，專案使用 Angular 14、TypeScript 4.6、RxJS 6.6、Leaflet 1.7 相容版本與 SCSS。版本範圍見 package.json，實際安裝版本由 lock 檔決定。

這是瀏覽器端渲染（CSR）網站：src/main.ts 啟動 AppModule，再載入 AppComponent。沒有啟用 SSR 或預先渲染，GitHub Pages 直接提供靜態產物；Node.js 用於開發、測試與建置。私人資料由瀏覽器直接連線 Google Drive，不需要另設儲存伺服器。

修改首頁應編輯 app.component.html、app.component.ts、app.component.scss 與 AppModule。目錄中保留的其他範本、路由或獨立元件，不代表它們都在目前啟動流程中使用；請先查實際引用再修改。

## 公開資料與私人資料

公開景點位於 src/assets/data/places.json，格式見 src/app/models/place.model.ts。地點 id 是私人紀錄的連結鍵；修改名稱或分類時應保留原 id，不要把刪除地點的 id 重新配給別處。

目前主要載入縣市圖層 src/assets/geojson/taiwan-counties.geojson；同目錄亦有區鄉資料。地圖預設中心與縮放常數見 src/app/core/constants/map.constants.ts。

私人文件內層格式如下；各欄位語意見使用指南：

```json
{
  "schemaVersion": 1,
  "records": {
    "1": {
      "category": "CAFE",
      "rating": 4,
      "visited": true,
      "parking": false,
      "seasonal": true,
      "seasonalNote": "每年 3～4 月賞櫻"
    }
  },
  "updatedAt": "2026-10-29T00:00:00.000Z"
}
```

category 為 null 代表沿用公開分類。舊文件缺少 category 時仍可讀取，由服務補上 null；不可把這個相容規則改成缺欄位即報錯。其餘狀態的 null 代表未設定，不能當成 false。

Drive 實際檔案外層另有 format、datasetId、commit、parents、data；上述 JSON 是其中的 data。不要把外層版本封套與使用者下載的內層備份混為一談。

## 必須保留的特殊規則

- 公開景點只載入一次並共用；私人類別只產生畫面資料副本，不直接修改原始陣列。登出、授權到期或清除覆寫後，必須能恢復公開分類。
- 地圖與清單都訂閱 PlaceService 的有效資料，不能各自合併私人類別。地圖重新載入標記前須取消舊訂閱，避免平移後留下多組資料流。
- 同組篩選為任一符合，不同組之間取交集。整個篩選區用 hidden 隱藏，保留側欄實例與勾選狀態。
- 左滑至少 48 像素，且垂直位移不得超過水平位移的 65%；不阻止原生垂直捲動。追蹤同一筆資料與同一 pointerId，排除多指及取消事件。滑動只顯示按鈕，不能直接開啟視窗。
- 螢幕閱讀器會把左右滑當成導覽，因此必須保留可點擊的隱藏揭露按鈕。編輯視窗開啟前先把焦點移回資料列，避免原按鈕移除後無法返回。
- 表單草稿與雲端待存草稿分開。前者也必須納入離開提醒、登出確認與帳號綁定，不能只檢查同步佇列。
- 非同步儲存必須先保存地點 id 與提交快照，完成後只能更新同一筆表單；不能在 await 之後直接使用可能已切換的目前地點。
- 開啟乾淨表單時，須等帳號確認及文件載入完成再填值；背景刷新不能覆蓋正在輸入的內容。儲存還要比對原表單基準值，防止用舊畫面覆寫新資料。
- LocationService 以 currentLocation$ 分享既有地圖定位結果，清單不可另開 GPS 或 IP 請求。先篩選再用 Haversine 直線距離排序副本；同距離維持來源順序，無效景點座標放最後，無有效定位時保留原順序。
- 初次有效定位可自動置中；後續定位只更新藍點。定位失敗時用台中火車站作中心，但不產生假的使用者藍點。IP 誤差以公里回傳，畫圓前須換算成公尺；本專案排除空值、越界及 0,0 座標。
- 側欄開關可能改變地圖尺寸，ResizeObserver 需要通知 Leaflet 重新計算，否則圖磚可能留白。
- Leaflet 彈窗使用 HTML 字串，不會自動套用 Angular 範本跳脫；所有資料文字需轉義，外部網址僅接受 HTTP 或 HTTPS。
- 「上」按鈕只觀察整頁捲動，不把地圖拖曳或清單內部捲動當成頁面捲動；平滑返回需尊重系統減少動畫設定。

授權、ETag、跨日與重試等儲存規則另見 [Google Drive 設定](GoogleDrive設定.md)。
